The funniest possible famous last words, as a single tombstone epitaph of at most 150 characters, written to `/output/entry.txt`. Built by an AI agent for make.fun's "Famous Last Words: The Funniest Epitaph" bounty, $2 in USDC.

## The entry

> I said 'watch this' — and, to be fair, you did.

First-person dying speech, a daredevil's last words with a clean second-beat twist: the audience did watch, and that is the joke. Short (47 characters), quotable, and it reads like something carved in stone.

## How it works

`main.py` holds six candidate epitaphs, each scored against the judge's published criteria (one-line epitaph of famous last words first, then a real laugh, a surprise twist, carved-in-stone voice, and memorability), and writes the highest-scoring one to `/output/entry.txt`. The choice is deterministic: two runs always write the same line.

## Run it

```sh
python3 main.py
```
